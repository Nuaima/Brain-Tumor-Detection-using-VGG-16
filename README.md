# 🧠 Brain Tumor Detection using VGG-16

---

### 🔍 Overview
This project implements a **Convolutional Neural Network (CNN)** to classify MRI scans as **tumor** or **no tumor**.  
The model leverages **transfer learning** with the **VGG-16** architecture and pretrained weights.  
The goal is to assist in automated brain tumor detection from MRI scans.

- **Validation Accuracy:** ~88%  
- **Test Accuracy:** ~80%

---

### 📂 Dataset
- **Source:** [Brain MRI Images for Brain Tumor Detection](https://www.kaggle.com/navoneel/brain-mri-images-for-brain-tumor-detection)  
- **Classes:**  
  - `NO` → No tumor (0)  
  - `YES` → Tumor (1)  
- **Format:** MRI scan images (varied resolutions)

---

### 🧠 Brain Tumor Background
A brain tumor is the growth of abnormal cells in the brain. Tumors can be:  
- **Benign:** Non-cancerous  
- **Malignant:** Cancerous, including primary (originating in the brain) and secondary (metastasized) tumors  

**Symptoms may include:** headaches, seizures, vision problems, vomiting, and mental changes.
